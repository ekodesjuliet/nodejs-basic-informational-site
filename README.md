# Basic Informational Site

A simple informational website built with Node.js using its built-in HTTP and FS modules.

## Features
- Serves `index.html`, `about.html`, and `contact-me.html`.
- Handles unknown routes with a custom `404.html` page.
- Uses HTTP status codes to indicate successful and unsuccessful requests.

## Run Locally

```bash
node server.js
```

Open [http://localhost:8080](http://localhost:8080) in your browser.
